# One core per line: <name> <git url>
#
# <name> must match the core's output, so that <name>_libretro.so is what its
# Makefile.libretro produces and what build.sh strips into lib/libretro/.
#
# Deliberately started with one small, permissively licensed, fast-building
# core. The point of the first build was to prove the toolchain, the sysroot
# and the bundle format -- not to ship a library.
2048 https://github.com/libretro/libretro-2048.git

# The first real emulator. Cross-built and run on hardware before being added
# here: the core loads, reports itself as "Snes9x 2010", negotiates RGB565 and
# runs a ROM.
#
# Its Makefile.libretro leaves CC unset under platform=unix (the `CC = gcc`
# line is commented out), so make's built-in default applies -- and an
# exported CC overrides a built-in, which is why the environment build.sh sets
# is enough. Nothing in the file needed patching. Worth re-checking when adding
# any other core: several platform branches in that same Makefile *do* assign
# CC outright, and one of those would silently ignore the cross compiler.
snes9x2010 https://github.com/libretro/snes9x2010.git

# Game Boy and Game Boy Color. The unix branch of its Makefile.libretro sets
# TARGET to gambatte_libretro.so and, like snes9x2010's, assigns no CC or CXX,
# so the exported cross compilers are the ones that build it. This core is
# C++, which is why build.sh exports CXX and not just CC.
gambatte https://github.com/libretro/gambatte-libretro.git

# Game Boy Advance. mGBA has no Makefile.libretro -- its libretro core is a
# CMake target -- so build.sh's core loop falls back to CMake when the
# makefile is missing. The flags live there, with the reasoning.
mgba https://github.com/libretro/mgba.git

# NES. Its unix branch assigns CC only under SunOS, so on this builder the
# exported cross compiler is what runs -- but that guard tests the *build*
# machine's uname, not the target, which is worth remembering if the build
# ever moves somewhere exotic. Its platform test is an exact `ifeq
# ($(platform), unix)` rather than a findstring, so the bare `platform=unix`
# the core loop passes is what it wants.
fceumm https://github.com/libretro/libretro-fceumm.git
